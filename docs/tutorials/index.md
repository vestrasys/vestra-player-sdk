# Tutorials

Tutorials take you from an empty folder to a working plugin, one step at a time. Each one builds on the previous and ends with something that runs in the player. If you want to look something up instead, use the {@link "@vestra-player/sdk" | API reference}, the [Concepts](../concepts/index.md) pages or the [How-to guides](../how-to/index.md).

| Tutorial | You will learn |
| --- | --- |
| [Getting started](getting-started.md) | The files of a plugin, the manifest, a first command, a window, tests and packaging. |
| Add a tool window _(coming soon)_ | A Slint window bound to plugin state, callbacks, showing and hiding it. |
| Add a settings page _(coming soon)_ | A page in the player's settings window that remembers its values. |
| Package and publish _(coming soon)_ | Building a `.vxp` package and listing it in the plugin store. |

You need Node.js 26 or newer and a copy of Vestra Player 0.2 or newer to try the plugins.
