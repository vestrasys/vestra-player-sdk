# Tutorials

Tutorials take you from an empty folder to a working plugin, one step at a time, and end with something that runs in the player. If you want to look something up instead, use the [Reference](../reference/index.md) tables or the {@link "@vestra-player/sdk" | API reference}; to understand how the pieces fit together, read the [Concepts](../concepts/index.md); for one task at a time, the [How-to guides](../how-to/index.md).

| Tutorial                              | You will learn                                                                       |
| ------------------------------------- | ------------------------------------------------------------------------------------ |
| [Getting started](getting-started.md) | The files of a plugin, the manifest, a first command, a window, tests and packaging. |

After it, the [Examples](../examples/index.md) walk through complete plugins (tool windows, panels, menus, filters, generated streams, translations), and [Publish a plugin](../how-to/publish.md) lists it in the plugin store.

You need Node.js 26 or newer and a copy of Vestra Player 0.2 or newer to try the plugins.
