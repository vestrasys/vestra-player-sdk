# Guidelines

The player's own interface is built from plugins, with the same API you use. These pages state the rules those plugins follow, so that yours fits in: what a user sees should not tell them which plugin drew it. They prescribe ("do", "do not"); for how the pieces work, read the [Concepts](../concepts/index.md), and for exact names, sizes and values, the [Reference](../reference/index.md).

## Interface

Tool windows, panels, the on-screen display and the video area: which theme tokens and widgets to use, the sizes of controls and rows, windows that apply changes at once instead of asking for OK, messages instead of status lines, and text that survives translation (length, CJK).

[Read the interface guidelines](interface.md)

## Menus

Where a command goes in the right-click menu (top level or a domain submenu, which group and order), how to share a submenu with other plugins, how to title an item (Title Case, `…`, check marks and radio dots), the right-click menu of a panel, and how to choose default key bindings that do not collide with the player's.

[Read the menu guidelines](menus.md)
