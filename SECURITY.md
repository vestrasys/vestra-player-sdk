# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability
reporting: the repository's **Security** tab ▸ **Report a vulnerability**.
Please do not open a public issue for a vulnerability.

## Supported versions

Fixes go into the latest minor release of `@vestra-player/sdk`.

## Scope

The SDK package (`@vestra-player/sdk`: plugin API types, test host, plugin
CLI, documentation tools) and the tooling in this repository.
